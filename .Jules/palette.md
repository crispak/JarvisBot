## 2024-05-24 - Conversational Empty States and Graceful Failure
**Learning:** For a chat bot backend without a UI, users expect immediate conversational guidance when things go wrong (e.g. attempting to list a to-do list before starting one) and when lists are empty. Returning Python traceback-style errors like `KeyError` or raw system formats like trailing index markers (`1. \n 2. \n`) significantly degrades the UX. Empty states should guide the user on the exact command they need to proceed.
**Action:** When building bot plugins, ensure all data storage access handles the "uninitialized" case by prompting initialization steps. Also, avoid showing raw data markers for empty lists; instead, output friendly prompts like "Your Todo list is empty. Add tasks using `@Jarvis todo add <task>`."
