## 2023-10-27 - Conversational UI (CUI) Empty States
**Learning:** In purely text-based conversational interfaces (like this Zulip bot), returning a completely empty message, or malformed empty structures (like `1. ` without an item) provides a poor user experience. Furthermore, text-based bots often serialize state (like a list) using string delimiters (e.g. `~`), which produces empty string elements when splitting that must be explicitly filtered out.
**Action:** When designing text commands that return lists or modify lists, always check for empty arrays/strings after deserialization and explicitly filter out empty elements. Return friendly empty-state messages (e.g., "Your ToDo list is empty! 📭") instead of blank space, and provide explicit error states for out-of-bounds removal operations.
