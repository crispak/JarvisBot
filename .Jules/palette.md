## 2024-05-24 - Improve Empty States for Todo List
**Learning:** Returning blank lists or lists with empty items is confusing UX for users interacting via text interfaces. A clear, friendly text response like "Your todo list is empty." offers better feedback on the empty state than returning formatted strings with no content.
**Action:** When working on text-based bots, ensure empty states are explicitly addressed rather than letting the code logic naturally generate an empty view.
